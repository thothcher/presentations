რესურსები

სლაიდები ერთი ნახევარია, მეორე — ხელით დაწერილი კოდი. აქ ის მასალაა, რომელსაც ლექციის შემდეგ ხსნი: მზა შაბლონები, ფორმები და პატარა ლაბორატორია JavaScript-ისთვის.

სამუშაო ფაილები

04 რესურსი

  1. 01 html templates HTML შაბლონები მზა გვერდების ნიმუშები — სტრუქტურა, სემანტიკა და განლაგება, საიდანაც შეგიძლია დაიწყო. thothcher.github.io/triple-web
  2. 02 html forms HTML ფორმები ველები, label-ები, ვალიდაცია და გაგზავნა — ფორმების პრაქტიკული ნიმუშები. thothcher.github.io/html-forms
  3. 03 js lab JS ლაბორატორია სავარჯიშოები JavaScript-ში — კოდი, რომელსაც პირდაპირ ბრაუზერში უშვებ და ცვლი. thothcher.github.io/js-lab
  4. 04 react & next.js React-ის სწავლა ორთვიანი გზა Angular-იდან React-სა და Next.js-მდე — გაკვეთილები, პრაქტიკა და თამაშები. thothcher.github.io/Learn-React

რიგითობა

რითი დავიწყო?

ერთი გზა, რომელიც მუშაობს: ჯერ სლაიდები გაიარე, მერე იგივე თემა ხელით დაწერე. კითხვა, რომელიც კოდის წერისას გაჩნდება, ლექციაზე არასდროს გიჩნდება.

  1. 01 გახსენი შესაბამისი პრეზენტაცია და გაიარე ბოლომდე.
  2. 02 აიღე შაბლონი ან ფორმა და გადააკეთე — ჯერ ისე, როგორც არის, მერე შენებურად.
  3. 03 ლაბორატორიაში გაამოწმე ლოგიკა — პატარა ფუნქციები, ერთი კონკრეტული კითხვა ერთ ფაილში.
  4. 04 DevTools ყოველთვის გახსნილი გქონდეს. ის, რასაც იქ ხედავ, ნამდვილია — დანარჩენი ვარაუდია.
