# Frontend Presentations Archive

A curated collection of lecture slides on frontend development topics, including HTML/CSS, JavaScript, and Angular. All presentations are open-source and run directly in the browser.

## Overview

This project serves as an archive of educational presentations covering:

- **HTML & CSS** — Fundamentals of semantic markup and styling
- **JavaScript** — Core language concepts, DOM manipulation, async patterns, and authentication
- **Angular** — Framework fundamentals, services, dependency injection, and authentication
- **Git** — Version control basics and workflows

## Presentations

### HTML & CSS
- [Tailwind CSS](https://thothcher.github.io/tailwindCSS/#1) — Utility-first approach to styling

### JavaScript
- [Conditions: if / else](https://thothcher.github.io/js-if-else/#1) — Conditional operators
- [Loops](https://thothcher.github.io/js-loops/#1) — for, while, do…while iteration
- [Authorization in JS](https://thothcher.github.io/js-auth/#1) — Authentication, tokens, and session management
- [Asynchronous JS](https://thothcher.github.io/js-async/#1) — Promise, async/await, and event loop
- [Introduction to JavaScript & DOM](https://ani-jijiashvili-tbc-it-adacemy.github.io/JS-DOM/#1) — DOM manipulation and event handling

### Other Topics
- [Git](https://thothcher.github.io/git/#1) — Version control fundamentals

### Angular
- [Angular — Introduction](https://thothcher.github.io/angular-intro/#1) — Components, templates, and project structure
- [Services & Dependency Injection](https://tumanishvilinikolozi.github.io/Services-DependencyInjection/#1) — Service architecture
- [Authorization in Angular](https://thothcher.github.io/angular-auth/#1) — Authentication guards and route protection

## Features

✨ **Interactive** — Fully functional presentations that run in any modern browser  
🎨 **Styled** — Built with Tailwind CSS for a modern, responsive design  
📱 **Responsive** — Works seamlessly on desktop and mobile devices  
🔍 **Searchable** — Filter presentations by category or search by keywords  
♿ **Accessible** — Semantic HTML and keyboard navigation support

## Navigation

- **Arrow keys** → Navigate between slides
- **O key** → Open overview mode
- **? key** → Show help

Use the filter buttons and search bar to find presentations by topic.

## Technology Stack

- **Tailwind CSS v4** — Direct browser compilation, no build step
- **Georgian Fonts** — Noto Sans Georgian, Noto Serif Georgian, IBM Plex Mono
- **Vanilla JavaScript** — No dependencies required
